# MA Logistics — Website

Container transport & freight forwarding across Southern Africa.
Built with Next.js 14 (App Router) + Tailwind CSS, using the tokens from
the **MA Brand Identity System v1.1 (Burgundy · 2026)**.

## Brand tokens
| Token | Hex |
|---|---|
| Cargo Maroon | `#3C0008` |
| Deck Maroon | `#5A0010` |
| Signal Amber | `#E8A33D` |
| Steel | `#4A2A2E` |
| Fog | `#D8C9CC` |
| Paper | `#F4F1EC` |

Fonts: Inter Tight (display), Inter (body), JetBrains Mono (data/tracking codes).

## Getting started
```bash
npm install
npm run dev
```
